# Project Statement

## Problem Statement

Keeping track of books by hand (in a notebook or on paper) makes it easy to
lose track of which books are available and which ones are issued. This
project provides a simple computer program to keep a basic record of books
and their status.

## Scope of the Project

This project covers the basic day-to-day tasks of running a small library:

- Keeping a list of books
- Adding new books to the list
- Searching for a book by name
- Issuing a book to a reader
- Returning an issued book
- Deleting a book from the list

It is a simple, single-file console program. It does not track who borrowed
a book, does not save data after the program closes, and does not use a
database.

## Target Users

- Students or beginners learning Python
- Anyone who wants a very simple way to keep track of a small set of books

## High-Level Features

1. **Display Books** — show every book and whether it is Available or Issued.
2. **Add Book** — add a new book with an ID, name, and author.
3. **Search Book** — find books whose name matches what you type.
4. **Issue Book** — mark a book as issued so it can't be issued again.
5. **Return Book** — mark an issued book as available again.
6. **Delete Book** — remove a book from the list.
